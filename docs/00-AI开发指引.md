# AI 开发指引

本文档为 AI 编码工具（如 Cursor、Copilot、Gemini 等）提供快速上下文概要，帮助 AI 在最短时间内理解项目结构并开始编写代码。

## 项目一句话概要

Next.js 16 + Hono 前后端一体化后台管理脚手架，MySQL + Drizzle ORM，Mantine UI，Zod 类型安全，RBAC 权限控制。

## 编码模式速查

### 新增 API 路由

```ts
// 1. 定义 Zod Schema → src/server/routes/{resource}/dtos.ts
// 2. 实现路由 → src/server/routes/{resource}/index.ts
// 3. 注册路由 → src/server/route-defs.ts (.route('/xxx', xxx))
```

### 新增 Service

```ts
// src/server/services/system/{resource}/{resource}.service.ts
// 规则: 错误用 throw AppError 子类，不用 return
// 数据库错误用 catch + throw handleDatabaseError(err)
```

### 新增前端 Hooks

```ts
// src/hooks/queries/{resource}.ts
// 用 createResource<TList, TDetail, TCreate, TUpdate, TQuery>({...})
// 自动生成 useList / useDetail / useCreate / useUpdate / useDelete
```

### 响应方式

```ts
return R.ok(data); // 200
return R.created(data); // 201
return R.success("操作成功"); // 200, data: null
// 错误: throw new NotFoundError('资源', id)
// 错误: throw new BusinessError('消息', ErrorCode.XXX)
```

### 权限中间件

```ts
requireAuth; // 需要登录
requirePermission("module:res:op"); // 需要特定权限
auditLog({ module, operation, description }); // 审计日志
```

## 关键约束

1. **中间件顺序不可更改** — `src/server/setup/middlewares.ts` 中 5 个中间件的注册顺序严格固定
2. **R 工具类依赖 contextMiddleware** — 必须先注册 `contextMiddleware` 才能使用 `R`
3. **Service 层用 throw 报告错误** — 不要在 Service 中 `return R.xxx()`
4. **Zod Schema 是唯一事实来源** — 类型从 Schema 推导，不手写 interface
5. **新路由必须注册到 route-defs.ts** — 否则 RPC Client 类型不生效
6. **权限命名: `{模块}:{资源}:{操作}`** — 如 `system:admin:list`
7. **超级管理员权限为 `['*']`** — 匹配所有权限检查
