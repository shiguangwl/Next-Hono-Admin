# 项目概览

> NextHonoAdmin — 基于 Next.js 16 + Hono 的前后端一体化企业级后台管理脚手架。

## 核心特性

| 特性           | 说明                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------- |
| 前后端一体     | Next.js App Router 承载页面，Hono 运行在 Next.js Route Handler 内处理 API                    |
| 端到端类型安全 | Zod Schema → TypeScript → RPC Client，全链路类型推导                                         |
| 共享 CRUD 模式 | 服务端提供 CRUD 中间件工厂与共享 Schema，客户端提供 React Query Hooks 工厂，新增模块可复用既有模式 |
| RBAC 权限      | 菜单/按钮级权限，支持 `requirePermission` / `requireAnyPermission` / `requireAllPermissions` |
| 可观测性       | Pino 结构化日志 + 审计日志 + requestId 全链路追踪 + R 工具对象统一响应                       |
| 生产可用       | Docker 多阶段构建、自动迁移/种子、环境变量运行时校验                                         |

## 快速启动

### 前置条件

- Node.js ≥ 20
- pnpm ≥ 9
- MySQL 8.0+

### 环境配置

```bash
# 1. 安装依赖
pnpm install

# 2. 编辑 .env.development（已有合理默认值，仅需修改数据库连接）
# DATABASE_URL="mysql://root:password@localhost:3306/next_hono_admin"

# 3. 初始化数据库（Schema 同步 + 种子数据）
pnpm db:push
pnpm db:seed

# 4. 启动开发服务器
pnpm dev
```

开发环境已配置 `AUTO_DB_MIGRATE=true` 和 `AUTO_DB_SEED=true`，启动时会自动执行迁移和种子。

### 默认账号

| 账号  | 密码     | 角色                       |
| ----- | -------- | -------------------------- |
| admin | admin123 | 超级管理员（拥有所有权限） |

### 可用命令

```bash
pnpm dev              # 启动开发服务器
pnpm build            # 生产构建
pnpm start            # 启动生产服务器
pnpm lint             # 代码检查
pnpm lint:fix         # 自动修复
pnpm db:generate      # Drizzle 生成迁移文件
pnpm db:push          # 同步 Schema 到数据库（开发用）
pnpm db:migrate       # 执行迁移（生产用）
pnpm db:studio        # 打开 Drizzle Studio（数据库可视化）
pnpm db:seed          # 运行种子数据
```

## 内置 API 模块

| 路径                  | 功能                              | 权限前缀                      |
| --------------------- | --------------------------------- | ----------------------------- |
| `/api/auth`           | 登录、登出、获取当前用户信息      | 公开（login）/ 需认证（info） |
| `/api/admins`         | 管理员 CRUD + 重置密码 + 分配角色 | `system:admin:*`              |
| `/api/roles`          | 角色 CRUD + 分配菜单              | `system:role:*`               |
| `/api/menus`          | 菜单 CRUD（树形结构）             | `system:menu:*`               |
| `/api/operation-logs` | 操作日志查询 + 删除               | `system:log:*`                |
| `/api/configs`        | 系统配置 CRUD                     | `system:config:*`             |
| `/api/storage`        | 文件存储与配置管理 API            | `storage:config:*` / `storage:file:*` |

### OpenAPI 文档

> 当前版本未集成 OpenAPI 自动文档生成。如需要，可通过 `@hono/zod-openapi` 扩展实现。

## 环境变量

通过 `src/env.ts` 使用 `@t3-oss/env-nextjs` 进行运行时校验，缺少必要变量时应用启动会立即报错。

| 变量名                     | 必需 | 默认值         | 说明               |
| -------------------------- | ---- | -------------- | ------------------ |
| `DATABASE_URL`             | ✅   | -              | MySQL 连接字符串   |
| `DATABASE_MAX_CONNECTIONS` | -    | `10`           | 连接池最大连接数   |
| `DATABASE_IDLE_TIMEOUT`    | -    | `20`           | 空闲连接超时（秒） |
| `DATABASE_CONNECT_TIMEOUT` | -    | `10`           | 连接超时（秒）     |
| `AUTO_DB_MIGRATE`          | -    | `false`        | 启动时自动执行迁移 |
| `AUTO_DB_SEED`             | -    | `false`        | 启动时自动执行种子 |
| `SESSION_COOKIE_NAME`      | -    | `auth_session` | 会话 Cookie 名称                               |
| `SESSION_TTL_DAYS`         | -    | `7`            | 会话有效期（天）                               |
| `COOKIE_SECURE`            | -    | -              | 是否启用 Secure Cookie                         |
| `CORS_ORIGINS`             | -    | `""`           | CORS 允许来源（逗号分隔多个域名）              |
| `LOG_LEVEL`                | -    | 开发 `debug` / 生产 `info` | 日志级别（fatal/error/warn/info/debug/trace） |
| `STORAGE_ENCRYPTION_KEY`   | -    | -              | AES-256 存储加密密钥（64 位 hex 字符串）       |
| `NODE_ENV`                 | -    | `development`  | 运行环境                                       |

环境变量文件加载规则（Next.js 标准）：

- `.env` — 所有环境加载
- `.env.development` — 开发环境覆盖（可提交，不放真实密钥）
- `.env.production` — 生产环境覆盖（模板，可提交）
- `.env.production.local` — 生产环境本地覆盖（不提交，放真实密钥）
