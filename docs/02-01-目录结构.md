# 目录结构

## 顶层目录

```
Next-Hono-Admin/
├── docs/                    # 项目文档（本文件所在目录）
├── drizzle/                 # Drizzle 生成的 SQL 迁移文件
├── public/                  # 静态资源
├── scripts/                 # 工具脚本
├── tests/                   # 测试文件（集中存放，避免散落到 src/）
├── src/                     # 源代码根目录
│   ├── app/                 # Next.js App Router 页面
│   ├── components/          # 共享 UI 组件
│   ├── db/                  # 数据库层（Schema + 种子 + 连接）
│   ├── hooks/               # React Hooks（包含 React Query 封装）
│   ├── lib/                 # 共享工具库
│   ├── server/              # Hono 后端（路由 + 服务 + 中间件）
│   ├── env.ts               # 环境变量运行时校验
│   └── instrumentation.ts   # Next.js 启动钩子（DB 初始化、监控初始化）
├── middleware.ts             # Next.js Edge Middleware（路由守卫初步检查）
├── next.config.mjs          # Next.js 配置
├── drizzle.config.ts        # Drizzle Kit 配置
├── biome.json               # Biome 代码规范配置
├── vitest.config.ts          # Vitest 测试配置
├── Dockerfile               # 多阶段 Docker 构建
├── docker-compose.yml        # Docker Compose 配置
├── .env.development          # 开发环境变量
└── .env.production           # 生产环境变量模板
```

## 业务模块划分规范

项目按业务领域划分目录，避免所有模块堆在 `system` 下：

| 目录 | 业务领域 | 示例模块 | 状态 |
|------|----------|----------|------|
| `system/` | 系统管理 | 管理员、角色、菜单、配置、操作日志 | 已实现 |
| `storage/` | 存储管理 | S3 配置、文件管理器 | 已实现 |
| `content/` | 内容管理 | 文章、分类、标签、评论 | 待创建 |
| `business/` | 业务模块 | 订单、商品、客户、合同 | 待创建 |
| `finance/` | 财务模块 | 发票、付款、对账 | 待创建 |

### 新增业务模块的目录结构

以新增「文章管理」模块到 `content` 目录为例：

**前端页面**：
```
src/app/(dashboard)/content/
└── article/
    ├── page.tsx
    └── components/
```

**后端服务**：
```
src/server/services/content/
└── article/
    ├── article.service.ts
    └── index.ts
```

**后端路由**：
```
src/server/routes/
└── articles/
    ├── dtos.ts
    └── index.ts
```

详见 [新增模块指南](./01-03-新增模块指南.md)。
