# 服务端开发

## 分层概览

```
Route Handler（请求入口）
    ↓ Zod 校验参数
Service（业务逻辑）
    ↓ Drizzle 查询
Database（数据存储）
```

三条核心规则：

1. **Route 层**：只做参数校验和流程编排，不写业务逻辑
2. **Service 层**：只处理业务逻辑和数据访问，通过 throw AppError 子类报告错误
3. **响应层**：统一使用 `R` 工具对象构造响应

## 路由层（Routes）

### 路由文件规范

每个资源模块包含以下文件：

```
src/server/routes/{resource}/
├── dtos.ts    # Zod Schema 定义 + TypeScript 类型导出
└── index.ts   # 路由实现（中间件 + Handler）
```

### dtos.ts 编写规范

```ts
// src/server/routes/admins/dtos.ts
import { z } from "zod";
import { createPaginatedSchema, PaginationQuerySchema } from "../shared";

// 实体 Schema（对外输出，不含 password 等敏感字段）
export const AdminSchema = z.object({
  id: z.number(),
  username: z.string(),
  nickname: z.string(),
  status: z.number(),
  loginIp: z.string().nullable(),
  loginTime: z.string().nullable(),
  remark: z.string().nullable(),
  createdAt: z.string(),
  updatedAt: z.string(),
});

// 创建输入 Schema
export const CreateAdminInputSchema = z.object({
  username: z.string().min(2).max(50),
  password: z.string().min(6).max(100),
  nickname: z.string().max(50).optional(),
  remark: z.string().max(500).optional(),
});

// 更新输入 Schema
export const UpdateAdminInputSchema = CreateAdminInputSchema.partial().omit({
  username: true,
});

// 查询 Schema（继承分页基础 Schema）
export const AdminQuerySchema = PaginationQuerySchema.extend({
  username: z.string().optional(),
  status: z.coerce.number().int().min(0).max(1).optional(),
});

// 分页响应 Schema
export const PaginatedAdminSchema = createPaginatedSchema(AdminSchema);

// TypeScript 类型导出（从 Schema 推导）
export type Admin = z.infer<typeof AdminSchema>;
export type CreateAdminInput = z.infer<typeof CreateAdminInputSchema>;
export type UpdateAdminInput = z.infer<typeof UpdateAdminInputSchema>;
export type AdminQuery = z.infer<typeof AdminQuerySchema>;
export type PaginatedAdmin = z.infer<typeof PaginatedAdminSchema>;
```

### 路由实现规范

```ts
// src/server/routes/admins/index.ts
import { Hono } from "hono";
import { zValidator } from "@/server/utils/validator";
import type { Env } from "@/server/context";
import { requireAuth, requirePermission, auditLog } from "@/server/middleware";
import { IdParamSchema } from "../shared";
import { R } from "@/server/utils/response";
import {
  AdminQuerySchema,
  CreateAdminInputSchema,
  UpdateAdminInputSchema,
} from "./dtos";
import {
  getAdminList,
  getAdminById,
  createAdmin,
  updateAdmin,
  deleteAdmin,
} from "@/server/services";

const admins = new Hono<Env>()
  .use("/*", requireAuth) // 本模块所有路由需要认证
  // 列表
  .get(
    "/",
    requirePermission("system:admin:list"),
    zValidator("query", AdminQuerySchema),
    async (c) => {
      const query = c.req.valid("query");
      return R.ok(c, await getAdminList(query));
    },
  )
  // 详情
  .get(
    "/:id",
    requirePermission("system:admin:query"),
    zValidator("param", IdParamSchema),
    async (c) => {
      const { id } = c.req.valid("param");
      return R.ok(c, await getAdminById(id));
    },
  )
  // 创建
  .post(
    "/",
    requirePermission("system:admin:create"),
    auditLog({
      module: "用户管理",
      operation: "创建",
      description: "创建管理员",
    }),
    zValidator("json", CreateAdminInputSchema),
    async (c) => {
      return R.ok(c, await createAdmin(c.req.valid("json")));
    },
  )
  // 更新
  .put(
    "/:id",
    requirePermission("system:admin:update"),
    auditLog({
      module: "用户管理",
      operation: "更新",
      description: "更新管理员",
    }),
    zValidator("param", IdParamSchema),
    zValidator("json", UpdateAdminInputSchema),
    async (c) => {
      const { id } = c.req.valid("param");
      return R.ok(c, await updateAdmin(id, c.req.valid("json")));
    },
  )
  // 删除
  .delete(
    "/:id",
    requirePermission("system:admin:delete"),
    auditLog({
      module: "用户管理",
      operation: "删除",
      description: "删除管理员",
    }),
    zValidator("param", IdParamSchema),
    async (c) => {
      const { id } = c.req.valid("param");
      await deleteAdmin(id, c.get("admin")!.adminId);
      return R.success(c, "删除成功");
    },
  );

export { admins };
```

## 中间件层（Middleware）

### 注册顺序（严格固定）

```ts
// src/server/setup/middlewares.ts
const PUBLIC_PATHS = new Set(["/api/auth/login", "/api/health"]);

function isPublicPath(path: string): boolean {
  return PUBLIC_PATHS.has(path);
}

export function setupMiddlewares(app: Hono<Env>): void {
  // ⚠️ 顺序不可更改
  app.use("*", requestContextMiddleware); // 1. 生成 requestId
  app.use("*", requestLoggerMiddleware); // 2. 请求日志（Pino）
  app.use("/api/*", corsMiddleware); // 3. CORS 跨域（在认证之前）
  app.use("/api/*", csrfMiddleware); // 4. CSRF 防护（在认证之前）

  app.use("/api/*", async (c, next) => {
    // 5. 会话认证（公开路径跳过）
    if (isPublicPath(c.req.path)) {
      c.set("admin", null);
      c.set("sessionId", null);
      c.set("permissions", null);
      return next();
    }
    return sessionAuth(c, next);
  });

  app.use("/api/*", async (c, next) => {
    // 6. 加载权限
    if (isPublicPath(c.req.path)) return next();
    return loadPermissions(c, next);
  });
}
```

### 可用中间件一览

| 中间件                         | 文件                 | 用途                                           | 默认状态    |
| ------------------------------ | -------------------- | ---------------------------------------------- | ----------- |
| `requestContextMiddleware`     | `request-context.ts` | 生成 requestId + AsyncLocalStorage             | ✅ 已启用   |
| `requestLoggerMiddleware`      | `request-logger.ts`  | Pino 结构化请求日志                            | ✅ 已启用   |
| `corsMiddleware`               | `cors.ts`            | CORS 跨域配置                                  | ✅ 已启用   |
| `csrfMiddleware`               | `csrf.ts`            | CSRF 防护                                      | ✅ 已启用   |
| `sessionAuth`                  | `session-auth.ts`    | 解析服务端会话，优先 Cookie，兼容 Bearer Token | ✅ 已启用   |
| `requireAuth`                  | `session-auth.ts`    | 断言已认证（Handler 级使用）                   | 按需使用    |
| `loadPermissions`              | `rbac.ts`            | 加载并缓存用户权限                             | ✅ 已启用   |
| `requirePermission(perm)`      | `rbac.ts`            | 校验单个权限                                   | 按需使用    |
| `requireAnyPermission(perms)`  | `rbac.ts`            | 校验任一权限                                   | 按需使用    |
| `requireAllPermissions(perms)` | `rbac.ts`            | 校验全部权限                                   | 按需使用    |
| `auditLog(options)`            | `audit-log.ts`       | 记录操作审计日志                               | 按需使用    |
| `apiRateLimit`                 | `rate-limit.ts`      | API 全局限流                                   | ❌ 未启用   |
| `loginRateLimit`               | `rate-limit.ts`      | 登录接口限流                                   | ✅ 手动调用 |

### 权限命名规范

```
{模块}:{资源}:{操作}

示例：
system:admin:list        列表查询
system:admin:query       详情查询
system:admin:create      创建
system:admin:update      更新
system:admin:delete      删除
system:admin:resetPwd    重置密码（扩展操作）
system:admin:assignRole  分配角色（扩展操作）
system:role:assignMenu   菜单分配
```

超级管理员权限：`['*']`（匹配所有权限）。

### 文件组织规范

### 编写规范

```ts
// src/server/services/system/admin/admin.service.ts

// 1. 业务逻辑通过 throw AppError 子类报告错误，不使用 return 错误
export async function createAdmin(input: CreateAdminInput) {
  const existing = await findAdminByUsername(input.username);
  if (existing) {
    throw new ConflictError("用户名已存在"); // 不要 return R.conflict(...)
  }

  const hashed = await hashPassword(input.password);
  try {
    const [result] = await db
      .insert(sysAdmin)
      .values({ ...input, password: hashed });
    return getAdminById(Number(result.insertId));
  } catch (err) {
    throw handleDatabaseError(err); // MySQL 错误 → 业务错误
  }
}

// 2. 不能删除自己、不能删除超级管理员 — 业务规则示例
export async function deleteAdmin(id: number, currentAdminId: number) {
  if (id === currentAdminId) {
    throw new BusinessError("不能删除自己的账号", ErrorCode.CANNOT_DELETE_SELF);
  }
  if (id === 1) {
    throw new BusinessError(
      "不能删除超级管理员",
      ErrorCode.CANNOT_DELETE_SUPER_ADMIN,
    );
  }
  await db.delete(sysAdmin).where(eq(sysAdmin.id, id));
}
```

```ts
// src/server/setup/error-handlers.ts
export function setupErrorHandlers(app: Hono<Env>) {

    const requestId = c.get("requestId");

      // ...
    }

    // 2. HTTPException (Hono 内部错误)
    if (err instanceof HTTPException) {
      // ...
    }

    // 3. 未知错误 (包装为 InternalServerError)
    // ...
  });
}
```

响应格式标准请参阅 [错误处理文档](./03-04-错误处理.md)。
