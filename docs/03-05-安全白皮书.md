# 安全白皮书

> 坚持安全零容忍红线，核心鉴权必须在后端完成。

## 1. 数据访问安全 (Data Access)

- **参数化查询**: 必须使用 Drizzle ORM 的模板字符串或自带方法，严禁任何形式的字符串拼接 SQL。
- **敏感字段保护**: Schema 定义中对于密码等敏感字段，在 DTO 返回阶段必须通过 Zod 进行剔除（Omit/Pick）。

## 2. 输入与输出防御 (Defense)

- **外部输入校验**: 所有来自 HTTP 请求的数据（Query, Body, Params）必须通过 `zValidator` 校验，禁止漏掉任何外部输入。
- **XSS 防御**: 前端 Mantine UI 默认进行转义，但在处理自定义富文本或原始 HTML 时，必须进行服务端清洗或校验。

## 3. 认证与鉴权 (Auth & AuthZ)

- **后端核心校验**: 前端隐藏元素仅用于提升体验，核心权限检查必须在 Hono 中间件 `requirePermission` 及其变体中完成。
- **敏感操作审计**: 所有 `POST/PUT/DELETE` 等修改数据的操作，必须挂载 `auditLog` 中间件记录操作人及变更。

## 4. 敏感信息管理 (Secrets)

- **环境变量**: 密码、Token 密钥、数据库连接字符串严禁硬编码在代码中。
- **读取方式**: 统一通过 `src/env.ts` 读取，该模块会在启动时校验变量是否存在且格式正确。
