# 测试指南

> 通过自动化测试保障重构的安全性和逻辑的正确性。

## 1. 测试策略

本项目采用 **Vitest** 驱动测试体系，测试文件集中放置在根目录的 `tests/` 下：

- **单元测试 (Unit)**: 针对 `services` 层和 `utils` 层的纯逻辑函数。
- **集成测试 (Integration)**: 模拟 Hono 请求流，验证从路由到数据库的完整链路。
- **冒烟测试 (Smoke)**: 验证数据库连接、迁移脚本等核心基础设施。

## 2. 目录结构

```bash
tests/
├── lib/           # 共享工具类测试
└── server/        # API 路由与业务逻辑测试
    ├── auth/      # 认证相关
    └── system/    # 系统管理模块
```

## 3. 运行测试

```bash
pnpm test          # 运行所有测试
pnpm test:ui       # 打开 Vitest UI 交互界面
pnpm test:coverage # 生成覆盖率报告
```

## 4. 编写规范

- **文件名**: 必须以 `.test.ts` 或 `.spec.ts` 结尾。
- **隔离性**: 测试用例之间不得有状态依赖，数据库测试建议使用事务回滚或独立的测试数据库。
- **Mock**: 优先使用 `vi.mock()` 处理外部服务依赖。
