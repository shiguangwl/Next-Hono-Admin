# 配置管理

> 严格区分开发、测试与生产环境配置，确保环境一致性。

## 1. 运行时校验 (t3-env)

项目使用 `@t3-oss/env-nextjs` 接管环境变量：

- **位置**: `src/env.ts`。
- **机制**: 在应用启动的第一时间根据 Zod Schema 校验 `process.env`。如果缺失关键配置（如 `DATABASE_URL`），应用将立即退出并报错。

## 2. 配置文件说明

严格遵循 Next.js 优先级：

1. **`.env.development`**: 开发环境默认值（可提交到仓库）。
2. **`.env.production`**: 生产环境配置文件（可提交到仓库，但**敏感值如数据库密码必须替换为强密码**，建议结合外部 Secrets 管理工具使用）。
3. **`.env.local` / `.env.production.local`**: 本地/生产私密配置（**严禁提交**，存放真实密钥）。

## 3. 变量列表

### 数据库配置

| 变量名                     | 类型    | 说明                              |
| :------------------------- | :------ | :-------------------------------- |
| `DATABASE_URL`             | URL     | 数据库连接字符串（必需）          |
| `DATABASE_MAX_CONNECTIONS` | number  | 连接池最大连接数（默认 10）       |
| `DATABASE_IDLE_TIMEOUT`    | number  | 空闲连接超时秒数（默认 20）       |
| `DATABASE_CONNECT_TIMEOUT` | number  | 连接超时秒数（默认 10）           |
| `AUTO_DB_MIGRATE`          | boolean | 启动时是否自动执行 SQL 迁移       |
| `AUTO_DB_SEED`             | boolean | 启动时是否自动初始化种子数据      |

### 会话与 Cookie

| 变量名                | 类型    | 说明                                          |
| :-------------------- | :------ | :-------------------------------------------- |
| `SESSION_COOKIE_NAME` | string  | 会话 Cookie 名称（默认 auth_session）         |
| `SESSION_TTL_DAYS`    | number  | 会话有效期天数（默认 7，最大 30）             |
| `COOKIE_SECURE`       | boolean | 是否显式启用 Cookie Secure；未设置时默认 `production=true`、其他环境 `false` |

### 安全配置

| 变量名                   | 类型   | 说明                                                |
| :----------------------- | :----- | :-------------------------------------------------- |
| `CORS_ORIGINS`           | string | CORS 允许的域名，逗号分隔                           |
| `STORAGE_ENCRYPTION_KEY` | string | AES-256 存储加密密钥（64 位 hex，可选）             |
| `NODE_ENV`               | string | 运行环境（development / production / test）         |

### 日志与可观测性

| 变量名                         | 类型   | 说明                                                               |
| :----------------------------- | :----- | :----------------------------------------------------------------- |
| `LOG_LEVEL`                    | string | 日志级别（fatal/error/warn/info/debug/trace/silent），默认开发 debug、生产 info |
| `OTEL_EXPORTER_OTLP_ENDPOINT`  | URL    | OTel OTLP 导出端点；已纳入 `src/env.ts` 统一校验，未设置时不启动 OTel SDK |
| `OTEL_SERVICE_NAME`            | string | OTel 服务名标识；已纳入 `src/env.ts` 统一校验，默认 `next-hono-admin` |

### 构建控制

| 变量名                  | 类型    | 说明                                                         |
| :---------------------- | :------ | :----------------------------------------------------------- |
| `SKIP_ENV_VALIDATION`   | boolean | 构建时设为 `true` 可跳过环境变量校验，用于 CI/CD 构建阶段   |

## 4. 安全红线

- **严禁硬编码**: 任何环境敏感的信息必须通过环境变量读取。
- **构建时忽略**: 复杂的后端密钥不应暴露在前端 `NEXT_PUBLIC_` 变量中。
